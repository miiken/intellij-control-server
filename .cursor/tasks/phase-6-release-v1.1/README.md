# Phase 6: Release v1.1 - Enhanced Features

## Overview
Second major release adding Tasks API and Advanced Refactoring capabilities based on team feedback from v1.0.

## Goals
- ✅ Release enhanced version with new features
- ✅ Address v1.0 feedback and issues
- ✅ Expand refactoring capabilities
- ✅ Add task management integration

## New Features in v1.1

### Tasks API (Phase 4)
- List IntelliJ tasks
- Get current task
- Switch between tasks
- Create new tasks
- Save/restore context per task

### Advanced Refactoring (Phase 5)
- Extract variable
- Inline method/variable
- Move class to different package
- Change method signature
- Safe delete

### Improvements
- Bug fixes from v1.0
- Performance optimizations
- Better error messages
- Enhanced documentation
